# Official ModXNA parent templates shipped with cpptraj.
#
# These 11 fragments are the consensus parents chosen from the ModXNA library
# (https://github.com/modna-ff). cpptraj ships only these files, not the
# full ModXNA corpus. Each file's atom order is the recommended TI
# shared-atom order for that chemical class.
#
# Load with:
#   parm $CPPTRAJHOME/dat/templatematch/DAA.mol2 name DAA
#
# Then map an analog:
#   templatematch analog template DAA mapout analog.map name analog.ti
#
# Combined nucleotides are mapped to a user residue (for example FLE = rA
# onto ERN = dA), not to these fragments. Use naorder on that residue to
# freeze a full-nucleotide template. For amino acids and small molecules
# generate your own parent (cysteine, benzene, ...) -- see the templatematch
# section of the cpptraj manual.
#
# file   class                    notes
# -----  -----------------------  ------------------------------------------
# 5PO    backbone, no phosphate   5'-OH cap
# DPO    backbone, phosphate      canonical phosphodiester
# DAA    purine base              deoxyadenine nucleobase
# DTT    pyrimidine base          deoxythymine nucleobase
# TMC    purine base + phosphate  rare combined fragment; 1 corpus member
# UFB    sugar, 2'-F
# A9Z    sugar, 2'-HH             bulky analog; prefer a real d-ribose if you have one
# DDD    sugar, 2'-HH + phosphate rare combined fragment; 1 corpus member
# RUR    sugar, 2'-OH             ribose
# OME    sugar, 2'-OMe
# RBO    sugar, 2'-OR             2'-O-benzyl, not plain ribose
